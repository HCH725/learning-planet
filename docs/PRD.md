# Learning Planet｜第一期範圍

Learning Planet 是跨年齡、多主題的學習宇宙；第一個世界是 2–6 歲幼兒與陪同家長使用的互動樂園。兒童不須閱讀、登入或作答，不因誤觸而受懲罰。

- Gate 1：輕量 Three.js 星球入口、同等功能 DOM 備援、幼兒世界首頁。未實作區域不可呈現為能玩的入口。
- Gate 2：動物森林（兔子、小鴨、小狗、兩種食物）；點擊回應、餵食、無懲罰錯誤回饋、音效生命週期、家長 PIN 與本機設定。提交同 SHA 預覽和裝置實測證據，交獨立 auditor，通過後再判定是否推進。
- Gate 3 之後：彩色泡泡、小小音樂屋、形狀花園；正式發布另取使用者核准。

非目標：未來世界實作、帳號、雲端進度、排行榜、廣告、外部推薦、聊天、即時生成內容、PWA、DB、CMS、服務端運算。

家長 PIN 僅降低幼兒誤觸，不是身份驗證或作業系統級限制。正式美術、中文語音、背景音樂、正式網域與可用真機仍待確認。
