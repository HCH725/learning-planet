# 安全與隱私基線

- 無兒童帳號、個人資料表單、廣告、追蹤 SDK、聊天、外嵌影片或外部推薦。禁止要求相機、麥克風及定位；執行期素材均自託管。
- 家長 PIN 是本地防誤觸，不是身份驗證；不保存明文，清除站點資料可重置；網站不可約束作業系統或瀏覽器介面。
- LP-005 在 Pages Preview 回應驗證 CSP、Permissions-Policy、nosniff、Referrer-Policy 及禁止嵌入；本文件不代表上述控制已部署。
- 無第三方 SDK 不代表主機側完全不處理請求資訊；對外提供前盤點存取與 CDN 日誌、用途與留存，按實際市場評估適用規範。
- 不把 GitHub 私有性當作預覽站的存取控制；分享預覽前確認其權限與匿名存取結果。
- 鎖定依賴，審查依賴差異與漏洞掃描；使用 GitHub PR 和獨立審計，不直接改正式站。
