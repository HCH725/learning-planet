# 真人語音錄製需求（台灣華語）

> 狀態：**尚未取得任何可用錄音**。本檔是交付給錄音者／配音者的工作單，不是素材授權證明。
> 在這個檔案被填上實際錄音、授權書與 `docs/ASSET_LEDGER.md` 的 `approved_by` 之前，App 內不得宣稱有真人語音。

## 為什麼需要

動物森林目前點動物只播放**動物實錄音效**（Freesound CC0，見 `docs/ASSET_LEDGER.md`），**沒有人聲報名字**。原案要求「動物短動畫＋動物叫聲＋名稱語音」，目前名稱僅以畫面文字＋`aria-live` 呈現。這一段是缺口，不得用 TTS 冒充真人。

## 三句主稿（必錄）

台灣華語、自然對幼兒說話的語氣（溫柔、清楚、略慢，不要新聞播報腔、不要娃娃音過度）。

| 檔案 | 文字 | 備註 |
| --- | --- | --- |
| `rabbit.wav` | 兔子 | 「子」輕聲，語速慢 |
| `duck.wav` | 小鴨 | 「小」清楚，不要連讀成「小鴨鴨」 |
| `dog.wav` | 小狗 | 「狗」尾音完整 |

## 三句選錄（若願意多錄，App 之後可支援）

| 檔案 | 文字 | 用途 |
| --- | --- | --- |
| `rabbit-eat.wav` | 兔子吃紅蘿蔔 | 餵食成功回饋 |
| `duck-eat.wav` | 小鴨吃麵包 | 餵食成功回饋 |
| `dog-eat.wav` | 小狗吃麵包 | 餵食成功回饋 |

> 不需要錄製任何誇獎、分數、連續使用邀請或「再玩一次」之類的 engagement 台詞。

## 錄音規格

- 格式：WAV，48 kHz / 24-bit（或 44.1 kHz / 16-bit），**單聲道**。
- 電平：峰值約 −3 dBFS，底噪低於 −60 dBFS；不要壓縮、不要限峰、不要加殘響／降噪重度處理。
- 環境：安靜小房間、軟裝為佳；麥克風離嘴 10–15 cm、略偏軸避免噴麥。
- 每句單獨一個檔，檔頭檔尾各留 0.3–0.5 秒靜音；不要在同一檔內錄多句。
- 交件：原始 WAV ＋ 一份去除首尾靜音、統一電平的版本（可註明使用的工具）。
- 若使用手機錄音也可以，但需附上裝置型號，並在安靜環境錄製；小蒨會再做剪段、淡入淡出、限峰與轉 MP3（與既有動物音效同一條處理管線）。

## 授權需求（缺一不可）

1. **錄音著作與表演人權利**：依台灣《著作權法》，錄音著作與表演人（錄音者／發聲者）權利需一併授權；請提供書面同意（可為 email 明確同意，需保留原始信件）。
2. **授權範圍**：非專屬、可永久、不可撤回、全球、可再授權給本專案之散布對象；允許**重製、公開傳輸、公開展示、改作**（剪段、淡入淡出、限峰、轉檔、與其他音效混音）。
3. **商用**：允許用於免費教育性質產品；若未來產品開始收費或加上廣告，需再次確認（建議一開始就同意「包含商業利用」以免日後重談）。
4. **姓名標示**：可選擇「標示姓名」或「不標示」；預設在 `docs/ASSET_LEDGER.md` 與 App 的授權頁標示。若不願具名，可寫「本專案配音員」。
5. **排除第三方內容**：不得包含背景音樂、他人錄音、TTS 合成聲或任何未授權素材。
6. **建議授權文字**：CC BY 4.0（可保留姓名標示）＋上述書面同意；若錄音者偏好，也可改為「專屬授權予本專案」。
7. **不要使用兒童聲音**：未成年人錄音涉及監護人同意與兒少隱私，第一版一律成人錄音，避免額外法務與隱私負擔。

## 交件後的處理（小蒨負責）

1. 以既有音訊管線轉為單聲道 MP3（與 `public/assets/preschool/audio/*.mp3` 一致），只做剪段／淡入淡出／限峰。
2. 更新 `docs/ASSET_LEDGER.md`：作者、來源（本專案委製）、授權、修改、署名要求、`approved_by`。
3. 在 `src/worlds/preschool/forest.ts` 的 `playFromGesture` 加入名稱語音（`kind: 'voice'`），沿用既有 unlock／靜音／背景 suspend／cooldown 生命週期。
4. 重跑 `npm test` 與 `npm run test:browser`，並補一個「點動物會播放名稱語音」的斷言（目前只有畫面文字斷言）。

## 目前搜尋結論（2026-11-21）

- Freesound：CC0 中文語音多為城市環境音／廣播，非單詞教學發音；動物實錄已用於音效，不能當人聲。
- Wikimedia Commons：中文發音檔多為**北京腔普通話**，且授權多為 CC BY-SA／GFDL，不符「台灣華語＋可重散布」條件。
- Lingua Libre：zh 錄音以普通話為主，無台灣華語兒語樣本。
- 因此**未採用任何外部人聲**，也沒有把普通話素材偽裝成台灣華語。
